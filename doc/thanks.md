# 9.1 Credits and community contributions

I could not make this documentation complete without honorable mentions and giving out credits where credits are due!

### Credits
First of all, I would like to mention most of the libraries used within this project to make everything possible.

- First of all, I need to thank the author that implemented Microvolts' encryption library [Qweha/MicroVolts-Crypt](https://github.com/Qweha/MicroVolts-Crypt)
- This emulator also uses the [inifile-cpp](https://github.com/Rookfighter/inifile-cpp) library by Rookfighter to parse the `config.ini` file
- To add 2FA support for graded accounts, Microvolts Emulator used [2fa-CPP](https://github.com/CosminPerRam/2fa-CPP) by CosminPerRam
- To easily parse CGD and CDB structure, I also decided to opt for [visit_struct](https://github.com/cbeck88/visit_struct) by cbeck88, check it out!
- I can't not mention [SQLite](https://sqlite.org/cintro.html) which made database connections possible.
- ...And so many other useful dependencies that you can find out inside the `vcpkg.json`! I cannot mention everyone, but I hope you'll appreciate all their hard work.
